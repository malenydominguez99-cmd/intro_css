## 📝 Descripción

Proyecto práctico de una página web temática de una cafetería, desarrollado para aplicar conceptos fundamentales de CSS mediante la estructura y el diseño de una interfaz sencilla.

La página presenta una cafetería ficticia, su menú de bebidas y un formulario de pedido. También incluye demostraciones visuales de diferentes propiedades de CSS.

## 🎯 Objetivo

Comprender y poner en práctica los fundamentos de CSS para dar estilo a una página web, organizar elementos y controlar la distribución de sus componentes.

## 📚 Contexto

Ejercicio realizado durante mi formación en el programa de **Dev.f, Bécalos y Traxión**, como parte del aprendizaje de desarrollo web.

## 🛠️ Pasos realizados

- Creación de la estructura de la página utilizando HTML.
- Vinculación de una hoja de estilos externa con CSS.
- Diseño de una interfaz temática para una cafetería.
- Incorporación de secciones de inicio, menú y pedido.
- Aplicación de propiedades de `display`: block, inline e inline-block.
- Práctica del modelo de caja (*Box Model*).
- Comparación de `content-box` y `border-box`.
- Aplicación de conceptos de herencia de estilos.
- Organización de elementos mediante Flexbox.

## 💻 Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** estilos, distribución y presentación de los elementos.

## 📌 Resultado y aprendizajes

Como resultado, se desarrolló una página web sencilla que permite visualizar distintos conceptos fundamentales de CSS aplicados a una misma interfaz.

Esta práctica me permitió reforzar conocimientos sobre:

- Estructura de páginas web.
- Selectores y propiedades CSS.
- Modelo de caja.
- Comportamiento de los elementos en pantalla.
- Herencia de estilos.
- Distribución de elementos con Flexbox.
